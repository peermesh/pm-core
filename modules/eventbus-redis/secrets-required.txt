# Redis Event Bus Provider - Required Secrets
#
# The Core Redis profile runs with requirepass and reads the same secret.
# Callers pass the mounted file path as RedisStreamsConfig.passwordFile
# (for example /run/secrets/redis_password). The provider refuses the file
# when it is group- or world-readable or a symlink, so mount it 0600 or 0400
# for the user the process runs as. Never put the password in the Redis URL.
#
#   openssl rand -base64 32 > secrets/redis_password
#   chmod 600 secrets/redis_password
